## 🚀 Project Overview
This Power BI project analyzes space mission data, focusing on:  
- Mission success rates  
- Launch attempts per year  
- Reliability trends and improvements  

It provides actionable insights into mission performance and overall reliability metrics.

---

## 🔧 Tools Used
- Power BI Desktop  
- DAX for calculations and measures  
- Power Query for data transformation
